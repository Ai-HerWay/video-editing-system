# Scene grammar

The physical metaphor comes from what the beat is *doing* in the story, not from
a template. Read the narrative function, then pick the construction and the
reason it moves.

## Function → construction

| The beat is... | Build it as... | And it moves because... |
|---|---|---|
| A hook or surprising claim | A cluster of cut-outs that gathers, plus one stamped verdict | The pieces collect, then the verdict lands on top |
| A set of alternatives | Mismatched tabs, cards, or labels arranged around one anchor | They fan out from a shared origin |
| A new concept | A taped note, an open notebook spread, or a lifted paper panel | The page opens or the note gets attached |
| A person or piece of evidence | A taped photo with a small evidence badge | A route draws toward the evidence |
| A comparison | Two unequal paper stations split by a centre divider | The cards separate, then settle into their roles |
| A process | A dotted path, numbered cards, or a stacked checklist | Each step appears because the one before it finished |
| A handoff | A file tag or object physically crossing between stations | The object being passed owns the transition |
| A transformation | One card held in place while its content or state changes | The existing object becomes the result |
| Proof or a result | Filed documents, checked rows, a receipt, an approval stamp | Evidence stacks up, gets checked, or gets stamped |
| A return or reuse | A folder reopening and pointing back to earlier material | A route closes into a loop |
| A closing prompt | Two or three large paper questions — not a dashboard grid | The questions land in the order they're spoken |

## Building one beat

1. Write the beat as a single sentence.
2. Find the concrete noun or action inside it.
3. Choose one physical metaphor that makes that noun or action visible.
4. Compose the strongest possible paused frame around it.
5. Add at most one hero move, one supporting move, and quiet background motion.
6. Leave the beat in a readable state that can hand an object, a direction, a
   colour, or a shape into the next one.

## Keeping it continuous

- Reuse paper sizes, edge weights, and shadow direction across the whole piece.
- Carry an object from beat to beat whenever the story keeps referring to the
  same thing.
- Give a recurring concept a stable colour and shape so it stays recognisable.
- Let the filmed subject stay the human anchor — don't re-centre every graphic
  on the speaker.
- Spend full-frame collage moments deliberately, to reset attention, rather than
  on every sentence.

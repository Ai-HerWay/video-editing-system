PICTURE SERIF RECONSTRUCTION

An approximate, working font family reconstructed from your supplied
Advercase specimen JPG. This is not the original or an official Advercase font.

FILES
Four styles: Regular, Italic, Bold and Bold Italic.
Each style is supplied as TTF (installable font) and WOFF2 (web font).
Font-preview.png shows text rendered with these TTF files.
fonts.css loads all four WOFF2 styles in HTML/CSS-based reel components.
preview.html is an editable browser preview; keep the font files beside it.

INSTALL
Unzip first. Open each TTF file and choose Install in your operating system.
In a compatible editor, choose the family "Picture Serif Reconstruction".
For web components, include fonts.css and use:
font-family: "Picture Serif Reconstruction", serif;
font-weight: 400 or 700;
font-style: normal or italic;

COVERAGE
A-Z, a-z, 0-9, space, middle dot and added common punctuation:
. , : ; ! ? ' " curly quotes, hyphen, en/em dash, underscore,
ellipsis, parentheses, square brackets, slash, plus, equals, asterisk.
Accented letters, currency signs, @, #, &, % and emoji are not included.
Your web renderer can use its fallback font for unsupported characters.

QUALITY
The supplied picture has small letters, texture and touching characters.
Outlines were traced, smoothed and separated, with approximate spacing.
Punctuation was drawn separately because it is missing from the picture.
Bold italic numerals use slanted reconstructed bold outlines to repair
unreliable overlaps. Other styles use their pictured letterforms.
Some irregular edges remain. Original kerning, hinting and full glyph coverage
cannot be recovered from this image. Best suited to display text and captions.

VALIDATION
All eight font files were reopened successfully with fontTools.
TTF and WOFF2 character mappings match for each style.
The included PNG was rendered using the generated TTF files.
